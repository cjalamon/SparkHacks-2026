#  Castly - Website for Connecting Creatives

Welcome to Castly, a website created for the purpose of connecting creatives within their respective area. Users will create their own accounts with their personal data, skills and wants/needs for their project. This will help creatives connect with people they need for their projects, ranging from animators, actors, photographers, and more. Castly can lead to better developed projects.

This project is developed using Python for backend, and React.js for the frontend.
